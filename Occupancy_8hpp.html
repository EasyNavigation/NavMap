Detailed Description

Probabilistic occupancy per NavCel: log-odds with clamping (as OctoMap), stored in an int16 layer in fixed point, and a three-state classification (as UFOMap).

This is the update rule only. Which NavCels a measurement hits or traverses (the sensor model) is decided by the algorithm that uses it.
