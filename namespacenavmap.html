◆ LinkType

enum class LinkType : uint8_t
strong

Main container for navigable surfaces, geometry, and layers.

A navmap::NavMap aggregates vertex positions, a list of navmap::NavCel triangles (global indexing), one or more navmap::Surface partitions, and a navmap::LayerRegistry with arbitrary per-NavCel scalar attributes.

Typical workflow

  • Fill positions, navcels, and surfaces.
  • Call rebuild_geometry_accels() to compute normals, areas, adjacency, and build per-surface BVHs.
  • Create layers via add_or_get() sized to navcels.size().
  • Query with locate_navcel(), raycast(), or closest_navcel(). Kind of a link between NavCels that are not adjacent in the mesh.

◆ combine_layer()

std::ptrdiff_t combine_layer ( NavMap & nm,
const std::string & dst,
const std::string & src,
CombineOp op,
const CombineOptions & options = {} )

Combine layer src into layer dst cell by cell with op.

Both layers must exist with one value per NavCel; their types may differ (values convert as in NavMap::layer_get: integers are rounded and clamped to their range). Which value is unknown is each layer's own LayerMeta::unknown (NaN allowed). Writing an unknown value into dst writes the unknown of dst; if dst has none, nothing is written.

Cells whose value changes are recorded with mark_changed() in dst. The provenance layer, if requested, gets source_id wherever the result is the source's value (MAX/MIN: it won or tied; ADD: it added something), even if the value was already the same.

Returns
Cells whose dst value changed, or -1 if a layer is missing, sizes differ or dst == src.

const DescriptorParams & params = {} )

Compute the selected descriptors as F32 layers of nm (created or overwritten).

Discs grow over the mesh adjacency from each NavCel (navmap/Iterators.hpp), so a descriptor never mixes floors. "clearance" casts a ray up from each centroid against every surface of the map: it is the room up to the next surface the map holds (the floor above), not to a ceiling that is not in the map; +inf when there is none within clearance_max.

Möller–Trumbore ray–triangle intersection.

Solves intersection between a ray (orig + t * dir, t > 0) and triangle (v0, v1, v2). Returns true on hit and outputs:

  • t: parametric distance along the ray (t > 0).
  • u, v: barycentric coordinates (with w = 1 - u - v).
Parameters
origRay origin.
dirRay direction (not necessarily unit length).
v0First triangle vertex.
v1Second triangle vertex.
v2Third triangle vertex.
tOutput ray parameter on hit (> 0).
uOutput barycentric u on hit.
vOutput barycentric v on hit.
Returns
True if the ray intersects the triangle with t > 0.
Warning
Numerical robustness depends on the geometry scale; kEps is set conservatively for typical mapping units (meters).

◆ simplify()

SimplifyStats simplify ( NavMap & nm,
const SimplifyParams & params = {} )

Simplify nm in place by half-edge collapses, cheapest first.

A vertex is removed only if all its NavCels have the same values in the kept layers and belong to the same surface, so every layer keeps its value at every point of the map: borders between values (an obstacle, unknown space, a different cost) are kept exactly. Open edges keep their shape (within max_error), topology is preserved (no folds, no new holes or bridges), and NavCels that are the end of a link survive. Layers, surfaces, links and vertex colors are carried over; NavCel and vertex ids change. Geometry accelerations are rebuilt.
