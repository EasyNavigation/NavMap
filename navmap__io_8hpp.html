Detailed Description

Save/Load utilities for NavMap to/from disk using ROS 2 CDR serialization.

Two API layers: 1) Message-level: save/load navmap_ros_interfaces::msg::NavMap directly. 2) Core-level (optional): save/load navmap::NavMap if the core headers are available, using navmap_ros::to_msg / navmap_ros::from_msg.

File format (version 2)
A small binary envelope followed by the ROS 2-serialized payload (little endian):
  • Magic "NAVMAP\0\0"
  • Version (uint32), codec (uint32: 0 none, 1 zlib)
  • Raw (CDR) size and stored size (uint64 each)
  • Payload: the CDR message, compressed by the codec

Version 1 files (magic, version, size, CDR; or a bare CDR payload) are migrated on load, with a deprecation warning, and rewritten in the current format.
