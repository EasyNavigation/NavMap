Detailed Description

Combining one layer into another with explicit operators, unknown-aware, with provenance.

Each source (a static prior, obstacles from a sensor, a keep-out zone) keeps its own layer, and a master layer is composed from them. Clearing a source layer then never erases another source: a prior survives sensor clearing because it is never written by the sensor.

The cost convention (Costs.hpp) is that of costmap_2d / Nav2.
